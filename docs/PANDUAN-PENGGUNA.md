# Panduan Pengguna — MRI — Megay Recruitment Intelligent

Versi aplikasi 2.0.0

## Apa itu MRI Personal Workspace?

MRI adalah ruang kerja rekrutmen pribadi untuk seorang HR. Semua data (kandidat, CV, lowongan, hasil screening, keputusan, karyawan) disimpan di browser Anda sendiri — bukan di server penjual. Google Drive Anda dipakai untuk backup, template, panduan, SOP, dan file yang ingin dibagikan.

AI di MRI bersifat rule-based (tanpa biaya API, tanpa internet). AI hanya memberi ekstraksi, skor, bukti, dan rekomendasi; keputusan akhir selalu Anda yang mengambil.

## Langkah pertama

1. Buka alamat aplikasi di Chrome, Edge, Firefox, atau Safari versi terbaru.

2. Isi nama Anda dan nama workspace. Nama Anda akan tercatat sebagai reviewer pada setiap keputusan.

3. Aplikasi berjalan di paket Demo (gratis). Coba dulu lewat tombol "Load Demo Data" di Executive Dashboard.

4. Sangat disarankan: langsung lakukan backup pertama di menu "Data & Backup", lalu aktifkan penyimpanan persisten bila diminta browser.

## Alur kerja harian

a. Job Requirement (menu 06): buat lowongan beserta kriteria dan bobot — atau mulai dari template di Knowledge Center.

b. CV Intake (menu 02): unggah CV satuan, banyak file, atau satu folder (PDF/DOCX/TXT, maks. 8 MB per file). Sistem membaca profil kandidat dan menandai duplikat (file sama, email sama, atau no. HP sama).

c. Screening Center (menu 03): pilih lowongan, klik "Screen Semua Kandidat CV Bank", buka baris kandidat untuk melihat skor per kriteria, bukti, kriteria yang terpenuhi/belum, lalu ambil keputusan: Pass, Talent Pool, Hold, atau Reject.

d. Candidate 360 (menu 04): riwayat lengkap satu kandidat, catat hasil tahap wawancara/assessment/offering/medical/hired.

e. Talent Pool (menu 05): kandidat yang disimpan untuk kebutuhan mendatang; "Re-match" ke lowongan baru kapan saja.

f. Employee Data Center (menu 09): setelah kandidat mencapai tahap HIRED, buat data karyawan; atau impor karyawan yang sudah ada lewat template Excel.

## Catatan penting tentang skor AI

Skor dihitung dari pendidikan, pengalaman, keahlian teknis, soft skill, kepemimpinan, dan sertifikasi yang terdeteksi di CV terhadap kriteria lowongan. CV hasil scan/foto tanpa lapisan teks tidak bisa dibaca (OCR belum didukung).

Kriteria tambahan (usia, domisili, dll.) hanya catatan untuk Anda tinjau manual dan tidak dinilai AI. Hindari kriteria berbasis agama, ras, atau suku tanpa dasar kualifikasi pekerjaan yang sah (UU Ketenagakerjaan Pasal 5-6).

## Backup, restore, dan pindah perangkat

Data ada di browser di perangkat ini. Jika data browser dihapus atau perangkat rusak, data ikut hilang — karena itu backup rutin wajib.

Backup: menu "Data & Backup" → "Unduh Backup". File .zip berisi seluruh data (dan file CV asli jika dipilih). Simpan di tempat aman atau kirim ke Google Drive.

Pindah perangkat: (1) di perangkat lama, buat backup; (2) di perangkat baru buka aplikasi, pilih "Pulihkan dari file backup" pada layar awal (atau menu Data & Backup); (3) pilih file .zip — seluruh workspace, termasuk lisensi, kembali seperti semula.

Memulihkan backup MENGGANTI seluruh data di perangkat tersebut. Aplikasi meminta konfirmasi terlebih dulu.

## Google Drive

Menu "Google Drive": klik "Sambungkan Google Drive" dan izinkan akses. MRI hanya meminta akses ke file yang dibuatnya sendiri (scope drive.file) — file lain di Drive Anda tidak terlihat oleh MRI.

MRI membuat folder "MRI Workspace" berisi: 1 Panduan, 2 Template Excel, 3 Backup Data, 4 Manual & SOP, 5 File Distribusi.

Yang bisa dilakukan: simpan backup ke Drive dan pulihkan dari Drive; unggah Panduan dan Template Excel; unggah manual/SOP atau file distribusi; salin otomatis laporan yang Anda ekspor ke folder File Distribusi lalu bagikan lewat tautan Drive.

## Paket dan lisensi

Demo (gratis): 15 kandidat nyata, 3 lowongan, tanpa ekspor laporan. Premium: 500 kandidat, 50 lowongan, ekspor Excel/PDF. VIP: tanpa batas.

Upgrade: menu "Paket & Upgrade" → tempel kode aktivasi dari penjual (atau unggah file .lic/.txt). Kode diverifikasi di perangkat Anda tanpa internet. Lisensi ikut tersimpan di backup.

## Privasi

Data kandidat tidak dikirim ke server MRI. Data hanya berpindah jika Anda sendiri mengunduh backup, mengekspor laporan, atau menyambungkan Google Drive Anda.

Gunakan perangkat pribadi/terkunci untuk data rekrutmen, dan jangan berbagi file backup sembarangan — isinya data pribadi kandidat.

## Pemecahan masalah

CV ditolak "tidak ada teks": file adalah hasil scan. Unggah versi PDF/DOCX asli.

PDF terproteksi password: buka proteksinya lalu unggah ulang.

Batas paket Demo tercapai: aktifkan kode Premium/VIP, atau hapus data demo dari Executive Dashboard.

Tab lain sedang membuka MRI: tutup tab lain — hanya satu tab yang boleh membuka workspace pada satu waktu agar data tidak bentrok.

Google Drive gagal tersambung: izinkan pop-up untuk situs ini, dan pastikan Client ID sudah diisi (lihat halaman Google Drive).
